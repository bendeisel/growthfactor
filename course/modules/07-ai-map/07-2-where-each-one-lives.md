# 07.2 Where each one lives

**Module:** 07 The AI Map
**Video:** ~4 min
**Needs first:** 07.1
**You finish with:** knowing exactly where to click for each thing

## Why this matters

Short lesson, purely practical. The AI features are spread across several
menus and people waste real time hunting.

## The map

[SHOT 07.2-01]

| What | Where |
|------|-------|
| Your six agents | **AI Agents** in the left nav |
| Editing an agent | AI Agents, click the agent |
| Agent Studio canvas | Inside an agent, or AI Agents > Agent Studio |
| Knowledge base | **AI > Knowledge Base** |
| Voice AI configuration | AI Agents, the voice agent |
| Voice AI call routing | **Settings > Phone Numbers**, the number's call config |
| Ask AI | Usually a persistent button or the AI menu |
| Conversation AI settings | AI, or Settings > Conversation AI |
| Workflow AI Builder | Inside Automation, when creating a workflow |
| Content AI | Inside the email and page editors |
| Reviews AI | Reputation or Reviews |
| AI usage and billing | Billing, see 07.5 |

## The one that catches everybody

**Voice AI is configured in two places.**

The agent itself, its personality, knowledge and behaviour, lives in AI Agents.

How calls reach it, the ring timing, forwarding and priority, lives on the
phone number in Settings.

That split is why voice agents so often look correctly configured and still
never answer a call. The agent is fine. The routing is not. See 09.8.
