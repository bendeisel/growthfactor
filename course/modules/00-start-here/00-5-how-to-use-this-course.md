# 00.5 How to use this course

**Module:** 00 Start Here
**Video:** ~4 min
**Needs first:** nothing
**You finish with:** a plan for the first week

## Read it or watch it

Every lesson exists twice. The written version has the exact steps, the exact
field values, and screenshots. The video is the same thing with someone doing
it on screen.

Neither is a summary of the other. Pick whichever suits you. Most people watch
first and then work from the written version with the account open on the
other screen, which is the way it was built to be used.

## The order is not a suggestion

Modules 00 to 06 build the objects your agents need: tags, calendars,
pipelines, payments, workflows. Module 07 and 08 set up the AI and what it
knows. Module 09 is the agents.

If you jump to module 09 first, you will be editing agents that fire off tags
you have not set up, booking into calendars you have not configured. It will
half work, which is worse than not working, because you will not know which
half.

Modules 10 to 14 are what you do once it runs. Those you can take in any order.

## What is in each lesson

- The steps.
- A **checklist** at the bottom. Print it or tick it, either way do not skip
  it, it is what catches the one setting you missed.
- A **test** section. Test on yourself before it touches a member. Every time.
- A **when it goes wrong** section on the lessons where things commonly do.

## When to ask

Post it in the community. Genuinely, post it, because your question is
somebody else's question and the answer helps four people instead of one.

Ask us directly when: something is broken rather than confusing, it involves
billing, or it involves a member being upset.

## The one rule

**Test on yourself before it touches your list.**

Put your own number in as a test contact. Tag yourself. Run the workflow.
Read what arrives on your own phone. Every single time, without exception.

The one mistake that is not recoverable in this course is sending something
bad to your whole database. Everything else is a settings change.
