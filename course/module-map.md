# Gym Coaching Course: Module Map

Status: **draft for Ben's approval.** Nothing below is written yet. This is the
list of modules, the lessons inside each, and what each one ships with. Once
this is signed off, the SOPs and lesson scripts get written against it.

Host: GoHighLevel Communities plus Courses (Memberships tab), same sub-account.
Every lesson ships **written first, video second**, so the written version is
the script for the video.

---

## The center of the course

Managed Agents (renamed from Super Agents) are the product. Everything else in
the course exists to make the agents work, or to read what they did.

A gym owner buys this to get four agents that run the front desk. The course
teaches them to edit those agents for their own gym, because an MMA gym and a
big-box gym need different answers out of the same agent.

Order of the course is deliberate: the agents fire off tags, calendars,
pipelines and forms, so those get built before the agents get touched.

## What every lesson ships with

1. **Written SOP.** Numbered steps, exact button names, exact field values.
   Written so someone can do the thing without watching anything.
2. **Shot list.** Every screenshot the written version needs: which screen,
   what to box, what to arrow, what to blur. See the screenshot note below.
3. **Video script.** The written SOP restructured for camera, with a hook,
   the demo, and one thing to go do.
4. **Checklist.** One page, printable, for the thing they just learned.
5. **Assets** where the lesson has one: KB template, tag dictionary, prompt
   text, snapshot, pipeline spec.

## Accuracy note

HighLevel's support portal is blocked from this environment by the network
egress policy, so the feature detail above comes from search summaries and
secondary sources, not the help docs directly. That is fine for a module map.
It is not good enough for "click this exact button" SOPs. Before I write the
step-level instructions I need one of: help portal access unblocked, screen
recordings of each flow, or you pasting the screens. Otherwise the button names
will drift from what is actually on screen, which is the fastest way to lose
trust with a paying member.
