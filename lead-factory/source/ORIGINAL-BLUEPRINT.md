Date: 2026-08-05 · Service: Growth Factor AI, $1,500/mo
Goal: Sell the core offer at full price; down-sell smart if no bite.

## The Offer

Lead Factory — $1,500/mo

Includes:
- Website (WordPress) — built on Growth Factor's existing site system, includes solid SEO + AI SEO setup + ongoing service
- 2 ads running (Facebook or Google — client's pick, one of each is ideal but not required)
- Lead-gen focused — that's the whole point of the name

What's excluded from "$1,500":
- Additional ad platforms (extra Google or extra Facebook) — sold as up-sell at full price only

Up-sells (when they ask):
- High-tier SEO / ongoing SEO extensive work
- Bigger / multi-platform ad spend
- Any custom request — quote it

The differentiation word: targeted ads, not "ads."

## The Funnel (4 stages)

**Stage 1 — Core Offer Push ($1,500)**
- Email + SMS (borderline, careful) + retargeting ads
- Go after anyone searching for ads/services in our geo (Nashville + region)
- Promise: website + 2 ads + lead gen done-for-you

**Stage 2 — No-bite → Split Offer**
- $1,000 ads only
- $500 website only
- Same positioning, just unbundled

**Stage 3 — No-bite → Niche Down**
- WordPress-interested leads → WordPress-only offer
- Ads-interested leads → ads-only offer
- Lower friction, easier yes

**Stage 4 — Closer Touch**
- Geo-targeted list (Nashville + region) gets phone follow-up
- The goal is to be local-close to high-value prospects

## Data Source — Datamoon

Tool: Datamoon (intent / search-data platform)

What we can pull:
- Anyone searching "ads" or ad-related terms in a niche
- Anyone searching "website" or WP-related terms in a niche
- Geo-filter: Nashville + region only (for closer touch)
- Vertical filters: any niche, focus on service businesses

Segmented lists we pull:
1. Ads intent list → fed into Stage 1 + retargeting
2. Website intent list → fed into Stage 1 pitch ("website + ads")
3. Both intent list → highest-priority leads

## Differentiator

The word: **targeted.**

Position Lead Factory around targeted ads powered by intent data, not "we run your ads."

Why it works:
- Saturated market — "Facebook ads agency" has 1000 competitors
- "Targeted ads using Datamoon intent data" has almost none
- Clients care about leads, not ads
- Geo + intent = story we can tell well
