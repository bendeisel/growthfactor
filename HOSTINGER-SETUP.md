## What I need from you

### 1. A Hostinger login code

This is a long code that lets me upload to your Hostinger account, the same
as logging in, but without me needing your password.

1. Log into hPanel (your normal Hostinger dashboard) in your regular
   Windows browser.
2. Click your account name, top right, then **API**.
3. Click **Generate token**.
4. Copy the code it shows you. It only shows it once, so copy it before
   closing that screen.
5. Paste that code back to me in chat. I'll save it somewhere that never
   shows up in the project files, never in anything I hand off, and never
   visible to anyone else who opens this project.

### 2. Confirm the domain

The site currently assumes it'll live at **fightersnashville.com**. Is that
right, or is there a different domain you want it on?

### 3. DNS, only if that domain isn't on Hostinger already

If fightersnashville.com is already hosted through Hostinger: nothing to do,
skip this.

If it's registered somewhere else (GoDaddy, Namecheap, wherever): it needs
to point at Hostinger before the site can go live there. You said you can
handle this part. Tell me where it's registered and I'll give you the exact
values to enter.

## What happens once I have those three things

1. I put the finished site on a preview link
   (`preview.growth-factor.ai/fightersboxing`), so the whole team can click
   through the real, live pages, not just this document.
2. The team reviews it and tells me what to change.
3. I make the changes and update that same preview link, so there's never a
   new link to re-share, it's always the same one.
4. Once everyone's happy, I push it to fightersnashville.com (or wherever
   we land) and it's live.

## Making edits later, once it's live

Easy. Tell me what to change, "swap this photo," "fix this typo," "add a
class," and I update it and put the change back on the preview or live
site, usually within minutes.

You never touch Hostinger directly for this, on purpose. Hand-editing a
file straight on the server is fragile: it can get silently wiped out the
next time anything's updated, with no record of what was lost. Going
through me instead means every change is saved and nothing gets lost by
accident.
